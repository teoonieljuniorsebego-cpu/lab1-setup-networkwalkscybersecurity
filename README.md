# Cybersecurity Lab Setup – Kali Linux on VirtualBox (WK1-PM1)

This repository documents the completion of the **WK1-PM1** lab task: setting up a fully functional Cybersecurity / Ethical Hacking testing environment using VirtualBox and Kali Linux.

## Objective

Create an isolated lab environment on a personal laptop/PC that allows safe practice of offensive security techniques. The lab uses:

- **VirtualBox** as the virtualization platform
- **Kali Linux** as the primary attacking machine
- A dedicated **NAT Network** in the `10.0.0.0/24` subnet

## Lab Requirements (Completed)

| Requirement                              | Status     | Details                                      |
|------------------------------------------|------------|----------------------------------------------|
| VirtualBox (latest recommended version)  | ✅ Done    | Installed and configured                     |
| Kali Linux as attacking machine          | ✅ Done    | Imported and running                         |
| Network subnet `10.0.0.0/24`              | ✅ Done    | NAT Network created                          |

This lab is intended for **educational and ethical hacking practice only**.
